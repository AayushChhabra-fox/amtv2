## subagent 4
- M4 is in place. Gate G1 turns a round-0 baseline matrix into a noise report and a required min_effect. Gate G2 checks that the eight known-good and known-bad designs keep their order up the ladder. A person signs each report, and a search brief does not start until both signatures are still current.
- G1, once per brief. Round 0 is every reference score plus popularity, random, and the LightGBM reference, at R0–R3, seeds 0–2, all on search_val. The binding half-width at a rung is the larger of the day-blocked bootstrap half-width and the three-seed t interval. min_effect must be at least twice the R3 half-width. The proposed starting value is 0.010. If the brief is below that floor, the report asks to raise min_effect, or to lengthen search_val or add seeds and rerun. Whether LightGBM beats production is recorded either way.
- G2, once per dataset and family set. The pairs are LightGBM on all features versus recency and category only, an MLP versus the same MLP on shuffled labels, fitted embedding similarity versus a seeded permutation, and fitted production-signal weights versus the production score. Good must rank above bad at R1, R2, and R3, and Kendall tau-b between R1 and R3 must be at least 0.6. An inversion only at R1 is re-validated by skipping R1 for that family. A low tau with the within-family order intact is re-validated by raising R1's train fraction. A failure at R2 or R3 stays a failure. Later runs on the same dataset and family set reuse the signature.

- Search briefs stop in ESCALATE until both gates are current. A brief with a pinned candidate, including the toy loop, is unchanged. Changing the brief, the spec, the manifest, or the report makes the signature stale.

```
amt noise --plan --brief briefs/nfy_article_rerank.yaml
amt noise --brief briefs/nfy_article_rerank.yaml --observations round0.json
amt sign g1 --brief briefs/nfy_article_rerank.yaml --manifest path/to/manifest.json --signer "Your Name"
amt ladder --plan --dataset datasets/nfy_article_rerank
amt ladder --dataset datasets/nfy_article_rerank --observations ladder.json
amt sign g2 --dataset nfy_article_rerank --signer "Your Name"
amt gates --brief briefs/nfy_article_rerank.yaml
```
- The train job already accepts the ladder design ids as --baseline. The reports are written from those scored observations. Signing is a separate step, so the NFY warehouse runs are ready to be signed once those jobs have returned metrics. Ruff is clean and the full suite passed, 106 tests.

## subagent 5

- M5 is in place. A search brief now runs as a resumable state machine against a fake agent and a fake jobs backend, and the walking-skeleton brief still goes proposal, critic, logistic model, smoke, and one job.
- The search loop is draft, then two improvement rounds, then a combine when two lineages exist, then confirmation of the promoted node. State is written to runs/<id>/state.json after every stage. A job key that is already recorded is not submitted again. The loop stops with ESCALATE.md when the critic revision cap, the debug cap (3 attempts), the schema-revision cap, or the DBU pool is hit.
- approval_mode is read from the brief and from amt run --approval-mode. none only writes the round digest. round_shortlist pauses after the critic, before any candidate is built. every_stage pauses after each stage until amt approve --run-id <id>.
- Role prompts in .cursor/agents/ now carry the output schema and the rubric. The critic checks task-block conformance, serve-time inputs, and near-duplicates. The reviewer checks that the claimed change is in the diff, that the model only sees the frames it is given, and that limits and holdouts are untouched. Context for each call is the 12 newest ledger lines, the best node per family, sibling lines for a draft or an improvement, and the full fix chain for a debug. Preflight rejects Spark, table names, network and subprocess calls, paths outside the candidate directory, imports outside the allowlist, and holdout split names, then runs the smoke fit. The implementer and reviewer hooks still deny writes outside candidates/<id>/, including harness/, amt/, briefs/, datasets/, resources/, and databricks.yml.

## subagent 6
- M6 is in place. A search brief can now run the one-time K=1 calibration, then the K=4 unattended run, and only then record that the full budget is ready for Phase 2.
- G3 calibration is amt run <brief> --scale calibration. That forces K=1 and approval_mode: every_stage, takes one draft lineage through R1–R3, and pauses after each stage until amt approve. It stops before confirmation, so the holdouts stay closed. The packet is gates/g3/<brief>/calibration_report.md (role prompts, spec, reviewer verdict, audit). Sign it once:

```
uv run amt sign g3 --brief <brief> --run-id <id> --signer "Your Name"
```

- A second calibration is refused.
- K=4 unattended run is amt run <brief> --scale small, and it starts only after G3 is signed. Round 1 proposes 8 drafts and keeps 4 across at least 3 families. Later rounds propose 3 improvements of each surviving lineage and keep 2, then one combine. Approval mode stays none. The run passes when at least 3 families are evaluated, every kill has a reason, spend stays inside the pool, and rounds 1–4 each have a digest.
- Agent statistics are written to runs/<id>/agent_stats.json and into report.md: bug rate (debug attempts divided by implementer calls), revisions, tokens, and wall-clock per node. amt stats --run-id <id> prints them.
-Full budget is amt run <brief> --scale full. After G3 is signed and a small run has passed, it writes runs/<id>/phase2_entry.md and does not start training.

## job wiring
Search and confirmation submit the real `train` and `confirm` jobs. `hello_train` is only the toy brief. Candidates are uploaded to an immutable volume snapshot. Round 0 and the ladder are matrix submits (`amt noise`, `amt ladder`). `amt dataset build`, `amt final`, and `amt reproduce` cover the other manual stages. `.env.example` holds auth, workspace, cluster, GPU, limits, and agent settings. `AMT_CLUSTER_ID` runs every job on one cluster; confirmation uses a one-time token. The demo brief is `briefs/nfy_demo.yaml`.
